# portfolio

The `/payroll_data` route proxies the dashboard published by
[`KaiElwood/payroll_data`](https://github.com/KaiElwood/payroll_data) on GitHub Pages.
Its React build and CSV live in that repository; dashboard updates do not require
copying generated files into this garden app. Keep the account Pages site on its
default `kaielwood.github.io` domain so the project Pages URL remains available.
